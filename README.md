## 🎯 Quick Start for Your Use Case

<details open>
<summary><h3>📷 For Photographers & Retouchers</h3></summary>

You already know your way around layers, masks, and curves. Spellcaster gives you AI superpowers without leaving GIMP.

**Your key tools:**
- **AI Upscale 4x** — six models including UltraSharp and RealESRGAN. Pick one, click Generate, done.
- **SUPIR AI Restoration** — state-of-the-art photo repair for damaged, noisy, or compressed images.
- **SeedV2R Upscale** — controllable hallucination (none/light/high) so you decide how much detail the AI invents.
- **Photo Restoration Pipeline** — one-click multi-stage: upscale + face fix + sharpen in a single pass.
- **AI Color Match** — steal the color palette from any reference image using MKL, histogram matching, or Reinhard transfer.
- **IC-Light Relighting** — change the lighting direction on any photo after the fact. 10 presets from Golden Hour to Neon.
- **Color Grading** — cinematic LUT application with adjustable strength.
- **Colorize B&W Photo** — add natural color to black-and-white photographs.
- **Object Removal** — paint over anything to erase it. LaMa inpainting, no prompt needed.
- **Face Restore** — fix blurry or damaged faces with CodeFormer.
- **AI Select by Description** — type "hair" or "shirt" to select it. Faster than any manual selection tool.

**Workflow tips:**
- Every result lands on a **new layer** — your original is never touched.
- Use the **Quick actions** (`Ctrl+Alt+E/U/F/B`) for rapid iteration — they use your last settings with zero dialogs.
- The **Upscaler Ratio Blender** lets you mix two upscale models (e.g. 40% sharp + 60% smooth) for exactly the look you want.

</details>

<details>
<summary><h3>🎨 For AI Art Beginners</h3></summary>

You don't need to understand models, samplers, CFG scales, or negative prompts. Spellcaster handles all of that.

**Start here:**
- **Text to Image** — type what you want to see. 25 scene presets auto-configure everything.
- **Image to Image** — feed in any photo and describe how to transform it.
- **Generate Anything** — creates a transparent object (a sword, a hat, a dragon) on its own layer, ready to composite. Works with any model.
- **Edit by Instruction** — type "make the sky orange" or "add a cat on the table" in plain English. Powered by Kontext/Flux 1 Dev.

**What makes it beginner-friendly:**
- Every tool has **presets** that auto-set every parameter. Pick "Portrait" or "Landscape" and click Generate.
- The **AI Prompt Enhancer** rewrites your simple prompt into an expert one automatically. It runs inside ComfyUI (no extra setup) and knows which model you're using — SDXL gets tags, Flux gets natural language, Klein gets concise descriptions. Just type "a cat" and it becomes a detailed, optimized prompt for your specific model.
- **Quick actions** let you one-click enhance, inpaint, upscale, or remove backgrounds with zero configuration.
- **Re-run Last** (`Ctrl+Alt+R`) repeats whatever you did with a new random seed — great for exploring variations.

**Next steps:** Try **Batch Variations** to generate 2-8 versions at once, then **Inpaint Selection** to fix just the parts you don't like.

</details>

<details>
<summary><h3>🎭 For Roleplayers & Character Creators</h3></summary>

Spellcaster has a full character production pipeline — from a selfie to a fully animated scene with consistent characters.

**The Magic Studios pipeline:**
1. **Casting Polaroids** — create a reusable face model from any photo or avatar.
2. **Body Double** — generate a full-body transparent cutout with face swap and background removal.
3. **Wardrobe Department** — AI outfit replacement with 40 presets. The outfit changes based on the scene.
4. **Set Design** — generate a background and composite your characters into it with AI lighting/shadow matching.
5. **Director's Chair** (Solo/Duo/Trio) — animate the scene as video with face re-injection to maintain identity across shots.

**Face tools:**
- **Face Swap** (3 engines: ReActor, Saved Model, mtb) — paste any face onto any image.
- **Face Identity Transfer** — generate new images that look like a specific person (IPAdapter FaceID).
- **Face Identity (Flux)** — Flux-native identity preservation at the attention level (PuLID).
- **Flux 2 Headswap** — hybrid pipeline: ReActor swap followed by a Klein refinement pass.

**For SillyTavern users:**
- 13 character cards auto-imported — Sceneshifter generates backgrounds, Portraitist creates expression sprites, Autonoma illustrates dramatic moments.
- `/studio-cast-all` + `/studio-body-all` enables automatic character compositing into every scene.
- Wan 2.2 Image-to-Video and First+Last Frame tools bring scenes to life as short animations.

**The Wizard Guild** is a standalone web UI where 13+ AI wizard characters walk you through every tool conversationally.

</details>

<details>
<summary><h3>🔧 For Developers & Power Users</h3></summary>

Under the hood, Spellcaster is a ComfyUI workflow orchestration engine with a GIMP frontend.

**Architecture:**
- **8 model architectures** supported: SD 1.5, SDXL, Pony, ZIT, Flux Dev, Flux Schnell, Flux 2 Klein (4B/9B), LTX, Wan.
- **NodeFactory DSL** — every tool is defined declaratively. Adding a new tool means writing a node spec, not a workflow JSON.
- **Crash-safe boot shim** — 3-tier recovery on startup: backup restore, GitHub download, visible error. GIMP never bricks.
- **LoRA management** — auto-detected per architecture, injectable into any generation workflow, favorites pinned across dialogs.

**Extensibility:**
- **Workflow Library** (`Filters > Spellcaster Tools > Workflow Library`) — import any ComfyUI workflow JSON and run it from GIMP with auto-extracted parameters.
- **PDB procedures** — every Spellcaster tool registers as a GIMP PDB procedure, callable from Script-Fu or Python-Fu.
- **17 keyboard shortcuts** auto-installed: `Ctrl+Shift` for primary tools, `Ctrl+Alt` for quick actions.

**ComfyUI integration:**
- Auto-detects server (local or remote via Antenna Installer).
- Queries `/system_stats` for GPU tier and auto-selects optimal parameters.
- All workflows submitted as JSON, polled for results, with privacy cleanup of temp files.

**Plugin structure:**
- `spellcaster_core/` — single source of truth, shared across SFW/NSFW repos.
- Auto-updater checks GitHub on launch and silently patches plugin files.
- Boot shim with backup/restore prevents update failures from bricking the installation.

</details>

## 📦 How to Install

### What You Need First

| App | What It Is | Why | Download |
|---|---|---|---|
| **ComfyUI** | The AI engine that does the heavy lifting | Required — this is what actually runs the AI models on your GPU | [github.com/comfyanonymous/ComfyUI](https://github.com/comfyanonymous/ComfyUI) |
| **GIMP 3** and/or **Darktable** | Free image editors (like Photoshop / Lightroom) | You need at least one — this is where Spellcaster's menu lives | [gimp.org](https://www.gimp.org/downloads/) / [darktable.org](https://www.darktable.org/install/) |
| **A GPU with 4+ GB VRAM** | NVIDIA recommended, AMD works too | The AI models run on your graphics card — more VRAM = more features | You probably already have one |

> **Never heard of ComfyUI?** That's fine. The installer can download and set it up for you. You'll never need to open it — Spellcaster talks to it behind the scenes. Think of it like an engine under the hood.
>
> **Don't have a GPU?** No problem. The installer's **Antenna Installer** connects to a ComfyUI server on another computer on your network (a friend's gaming PC, a cloud instance, etc.).
>
> **Don't want to use GIMP or Darktable at all?** You can skip them entirely and control Spellcaster through [The Wizard Guild](#-the-wizard-guild) — an AI chatbot that handles everything for you.

**Want the AI chatbot experience (The Wizard Guild)?** The installer adds a small LLM that runs natively inside ComfyUI — no separate server needed. See the [Wizard Guild setup guide](#how-to-set-up-the-wizard-guild).

### How The Scaffold Brain Works

Underneath The Wizard Guild sits a four-layer AI brain routing requests into ComfyUI:

1. **You say what you want** — to a Guild Wizard, or via any external chat app (Signal, SillyTavern, OpenWebUI)
2. **The MetaWizard maps your intent** — classifies what you want (enhance, generate, restore, video, etc.) and routes to the right sub-wizard
3. **The sub-wizard collects parameters:**
   - **SpellcasterWizard** — for enhancement nodes (Klein, detail, reference)
   - **PipelineWizard** — for multi-step operations (photo restore, SUPIR, LTX video, WAN video, SeedVR2 upscale) with step-by-step guidance and curated presets
   - **WorkflowWizard** — for any arbitrary ComfyUI workflow from your library
4. **ComfyUI executes** — the scaffold translates the conversation into a ComfyUI JSON workflow, submits it, polls for results
5. **The result is delivered** — right back into your browser, chat window, or messenger

## ❓ FAQ

<details>
<summary><strong>What GPU do I need?</strong></summary>

Any NVIDIA GPU with 4+ GB VRAM works. AMD GPUs work too (via ROCm on Linux or DirectML on Windows). The installer detects your GPU and only shows features your hardware can run — if you have 4 GB, you won't see options that need 16 GB.

For best results: 8+ GB VRAM handles most tools. 12+ GB unlocks video generation (Wan 2.2, LTX 2.3) and large models (Flux 2 Klein 9B). 16+ GB runs everything at full quality.

</details>

<details>
<summary><strong>Do I need to understand ComfyUI, models, or samplers?</strong></summary>

No. Every tool has expert-tuned presets that auto-configure everything. You never need to open ComfyUI, pick a sampler, set a CFG scale, or write a negative prompt. The AI Prompt Enhancer even rewrites your simple prompts into expert ones automatically.

</details>

<details>
<summary><strong>Can I use my own ComfyUI workflows?</strong></summary>

Yes. Open `Filters > Spellcaster Tools > Workflow Library` to browse and run any workflow JSON on your ComfyUI server directly from GIMP. Parameters are auto-extracted and presented as a dialog.

</details>

<details>
<summary><strong>What's the difference between the 3 face swap tools?</strong></summary>

- **Face Swap (ReActor)** — the default, best all-around quality.
- **Face Swap (Saved Model)** — uses a pre-built face model library, so you don't need the source photo every time.
- **Face Swap (mtb)** — alternative engine with multi-face indexing for group photos.

For Flux 2 quality, use **Flux 2 Headswap** which runs ReActor first, then a Klein refinement pass for seamless blending.

</details>

<details>
<summary><strong>What's the difference between Upscale 4x, SeedV2R, and SUPIR?</strong></summary>

- **Upscale 4x** — fast, faithful upscaling using traditional super-resolution models (UltraSharp, RealESRGAN, etc.). Best when you want a larger image without changing anything.
- **SeedV2R Upscale** — controllable hallucination. You choose none/light/high to decide how much detail the AI invents. Good for creative upscaling.
- **SUPIR AI Restoration** — state-of-the-art restoration for damaged, noisy, or heavily compressed images. Slower but highest quality repair.

</details>

<details>
<summary><strong>What is the Flux 2 Detail Enhancer?</strong></summary>

A targeted enhancement tool with 10 presets: face, eyes, hands, skin, hair, feet, clothing, jewelry, full body, and custom. It uses Flux 2 Klein to selectively improve specific regions of your image without affecting the rest. Great for fixing common AI generation artifacts like bad hands or blurry eyes.

</details>

<details>
<summary><strong>What does Generate Anything / Generate Object do?</strong></summary>

Both create transparent objects on their own layer — a sword, a hat, a coffee cup, a dragon. **Generate Anything** (in the Generate menu) works with any installed model. **Generate Object** (in the Flux 2 menu) uses Flux 2 Klein and matches the lighting of your current canvas so the object blends naturally when composited.

</details>

<details>
<summary><strong>What is the crash-safe boot shim?</strong></summary>

A 3-tier recovery system that prevents GIMP from bricking if the plugin files get corrupted during an update. On startup: (1) try loading normally, (2) if that fails, restore from backup, (3) if backup is missing, download fresh from GitHub, (4) if everything fails, show a visible error instead of silently breaking. Your GIMP installation is always recoverable.

</details>

<details>
<summary><strong>Can I run ComfyUI on a different machine?</strong></summary>

Yes. The Antenna Installer (on the installer Welcome page) auto-detects ComfyUI servers on your network and configures everything. You can also manually set the server URL in Settings. This means you can run GIMP on a laptop with no GPU and use a gaming PC or cloud instance for the AI processing.

</details>

<details>
<summary><strong>How does the AI Prompt Enhancement work?</strong></summary>

A small LLM (Qwen3 4B, ~2.5 GB) runs natively inside ComfyUI. When you type a short prompt like "a cat", the LLM rewrites it into an optimized prompt for your specific model — SDXL gets comma-separated tags with quality tokens, Flux gets flowing natural language, Klein gets concise descriptions. The LLM auto-unloads during image generation to free VRAM and reloads when needed. No separate server, no configuration. If you already run KoboldCPP or Ollama, Spellcaster uses those as a fallback automatically.

</details>

<details>
<summary><strong>Does anything leave my computer?</strong></summary>

No. Everything runs 100% locally. No cloud APIs, no accounts, no telemetry, no content filters. The only network traffic is between GIMP and your ComfyUI server (which can be localhost). The auto-updater checks GitHub for new versions, but that's opt-in.

</details>

<details>
<summary><strong>How do I use the premium dark-purple theme?</strong></summary>

Set `"apply_theme": true` in your Spellcaster `config.json`. The theme reskins both GIMP and Darktable with a dark purple aesthetic. It's purely cosmetic and opt-in.

</details>
