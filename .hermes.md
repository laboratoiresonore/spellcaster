# .hermes.md — Hermes guide for spellcaster

**spellcaster** is the web research and discovery agents repository. It contains automation for legal research, news monitoring, and OSINT workflows.

## Hermes-native-first rule

**Before writing ANY new code, check if a Hermes-native system already exists.** Use these instead of building:

| Need | Hermes-native system |
|------|---------------------|
| Fetch secrets | `msg.tell_hermes(topic='hermes_action', action='broker_get_and_set_env')` |
| Schedule recurring | `hermes cron create <schedule> --script <path>` |
| GitHub events | Existing webhook at `:8644/webhooks/github` |
| Persistent tasks | `hermes kanban create --board <slug>` |
| Cross-agent messages | `msg.tell_claude` / `msg.tell_hermes` in `code_index.db` |
| Code search | `code.search_hybrid` (hermes-code-index plugin) |

## Git practice

- **ALWAYS run `hermes_atlas.py --query <topic>` before touching code**
- If atlas returns 0 hits, file a coverage gap card
- Use `git commit --only <paths>` for partial commits (avoid `git add -A`)
- Never commit `.env`, API keys, or credentials
