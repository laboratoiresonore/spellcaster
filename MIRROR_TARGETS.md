Rules:

- **C is the only source you edit by hand.** All other surfaces are downstream.
- **Surface 1** is in-repo and gets synced on PR via `mirror_drift.py --fix` (one-direction copy of C → 1).
- **Surfaces 2, 3, 5, 6** are cross-repo. The auto-patch bot detects changes in C and lands a `chore(vendor): sync spellcaster_core@<sha>` PR in each consumer. When you edit C, expect 4 follow-up PRs land within ~1 hour.
- **Surface 4** is not source — it's a runtime install target. The Krita bridge installer rewrites it from C on every run.

## §3 — The CI failsafe

`.github/workflows/mirror-drift.yml` runs `tests/mirror_drift.py` on every PR that touches:

- `comfyui-spellcaster/spellcaster_core/**` (canonical)
- `plugins/gimp/comfyui-connector/spellcaster_core/**` (in-repo mirror)

The check md5s every tracked file in both paths and asserts byte-equality. Failures block merge.

Run locally:

```
python tests/mirror_drift.py             # check only, exit 1 on drift
python tests/mirror_drift.py --fix       # copy C → 1 (one direction)
python tools/check_mirror_sync.py        # full 6-surface report
```

## §4 — When a surface drifts

1. **Determine direction.** Was C ahead, or was a downstream surface ahead?
2. **If C was ahead:** Run `tests/mirror_drift.py --fix` (in-repo) and let the auto-patch bot handle cross-repo. **Never copy a downstream surface back into C** without owner review — that's how regressions enter canonical.
3. **If a downstream surface was ahead** (someone edited 2/3/5/6 directly): land the change in C in a follow-up PR with `fix(canon): backport <change> from surface <n>`. Then let the auto-patch bot re-propagate so all surfaces converge.
4. **If multiple surfaces diverged independently:** flag for the user. Do not auto-resolve. This is the failure mode that motivated this file's existence — PR #20 (2026-05-13) caught a 4-week-old drift where surface 1 held a fix that C had lost.

4. Run a full sync to seed the new surface from canonical.
