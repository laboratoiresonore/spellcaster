## Tier 1 — drop-in supersessions (ship soon)

### 1. SAM 3.1 → `build_sam3_segment`, `build_sam3_mask`, `build_sam3_extract`

**Current**: SAM 3 checkpoints (pipeline uses `sam3_*` class nodes)  
**Replacement**: SAM 3.1 — [https://huggingface.co/facebook/sam3.1](https://huggingface.co/facebook/sam3.1)  
**Released**: 2026-03-27 (Meta AI)  
**Risk**: low | **Confidence**: 0.97

Fully backwards-compatible API drop-in. New "Object Multiplex" feature adds shared-memory joint multi-object tracking: up to 7× faster at 128 objects, double frame rate at medium counts, zero accuracy loss versus SAM 3. Gated on Hugging Face — submit an access request before download.

### 2. HyperSwap 256 → `build_faceswap`

**Current**: `inswapper_128.onnx` (128×128 native swap resolution)  
**Replacement**: `hyperswap_1a_256.onnx` / `hyperswap_1b_256.onnx` / `hyperswap_1c_256.onnx` (~403 MB each)  
**Source**: [https://huggingface.co/facefusion/models-3.3.0](https://huggingface.co/facefusion/models-3.3.0)  
**Released**: June 2025 (ReActor integration stable: May 12 2026)  
**Risk**: low | **Confidence**: 0.95

Native 256×256 output (4× pixel count vs inswapper_128) at comparable or better identity fidelity. Drop-in for ReActor — place files in `models/hyperswap/` and select in the swap_model dropdown. Start with `hyperswap_1a` — there is an active bug report about a black-circle artifact on `1b`. `reswapper_256.onnx` (currently used in Klein headswap) may coexist; no removal needed.

## Tier 2 — additive new builders (needs node-pack install)

### 5. HiDream-O1-Image 8B → new `build_hidream_txt2img` / `build_hidream_edit`

**Source**: [https://huggingface.co/HiDream-ai/HiDream-O1-Image](https://huggingface.co/HiDream-ai/HiDream-O1-Image) | MIT license  
**Released**: 2026-05-08–10 | **Risk**: medium | **Confidence**: 0.95

Pixel-level Unified Transformer (UiT) — operates directly in pixel space, no external VAE, no disjoint text encoder. Supports txt2img, instruction-based editing, subject-driven personalization up to 2048×2048. 8B params; benchmarks above 27B Qwen-Image on several evaluations. ComfyUI native support confirmed (PR #13817, workflow browser). FP8 quant (`drbaph/HiDream-O1-Image-FP8`) fits 16 GB. **Not a replacement** for SDXL/Flux — a distinct new architecture warranting its own builder pair.

### 14. ComfyUI-TurboQuant → node pack for all DiT builders
