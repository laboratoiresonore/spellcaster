## Tier 1 — Drop-in supersessions (ship soon)

These are well-characterised, available today, fit 16 GB VRAM, and require no new node-pack installs beyond what spellcaster already uses.

### 1. ComfyUI v0.27.0 — Native Int8 Quantization
- **Affects:** all `build_klein_*`, all Flux-based builders
- **What changed:** Framework-level int8 quantized model loading with Turing-GPU-aware optimizations. Klein 9B at int8 fits comfortably within 16 GB. Also adds `ConditioningMultiply` node.
- **Action:** Update ComfyUI installation to v0.27.0. No workflow changes required.
- **Source:** https://github.com/comfyanonymous/ComfyUI/releases/tag/v0.27.0 (2026-06-30)

### 2. LTX-2.3 via Kijai/LTX2.3_comfy (updated Jun 30) + nvfp4 community quant (Jul 5)
- **Affects:** `build_ltx_video`
- **What changed:** LTX-2.3 is a full generational upgrade over the 0.9.8 branch: adds audio-to-video, video-to-video, multi-language (9 languages). The community `Plaguekind/ltx2.3` pack adds nvfp4 (native RTX 5060 Ti Blackwell FP4 tensor core) and int8 ConvRot variants that fit well within 16 GB.
- **Action:** Update ComfyUI-LTXVideo node pack; download Kijai/LTX2.3_comfy weights (nvfp4 variant). Update `build_ltx_video` to reference new model name.
- **Sources:** https://huggingface.co/Kijai/LTX2.3_comfy · https://huggingface.co/Plaguekind/ltx2.3

### 3. Google TIPSv2 DPT — Unified Depth + Normals + Segmentation (Jul 1)
- **Affects:** `build_depth_map_v3`, `build_normal_map`
- **What changed:** Single DPT-head model (4 size variants: b14 → g14) that outputs depth, surface normals, and semantic segmentation simultaneously. Replaces both `da3_large.safetensors` and the separate normals model with one inference pass. Apache-2.0, available today at `google/tipsv2-l14-dpt`. The l14 variant (~3 GB VRAM) is the optimal balance.
- **Action:** Wire `google/tipsv2-l14-dpt` into `build_depth_map_v3` and `build_normal_map` via a unified ComfyUI node. Benchmark against DA3-large to confirm depth quality parity.
- **Source:** https://huggingface.co/google/tipsv2-l14-dpt

## Tier 2 — Additive new builders (needs node-pack install or VRAM check)

### 4. Qwen-Image-2.0-RL (Jun 25) + Qwen-Image-Flash (Jun 2)
- **Affects:** `build_qwen_edit`
- **What changed:** Two follow-on releases on the Qwen-Image-2.0 backbone. RL post-training (GRPO) measurably improves visual quality and instruction-following. Flash distillation reduces inference to 2–4 steps. Official weights not yet on HF but Qwen team track record suggests release within 1–2 weeks.
- **Action:** Monitor `Qwen-Team` HF org; drop-in replacement once weights appear.
- **Sources:** https://huggingface.co/papers/2606.27608 · https://huggingface.co/papers/2606.03746

### 5. Hunyuan3D 2.1 — PBR Material Synthesis (Jul 1, community mirrors)
- **Affects:** `build_hunyuan_3d_textured`, `build_hunyuan_3d_mesh`
- **What changed:** Adds full PBR material output (albedo, roughness, metallic) from a single image — a major upgrade over the UV-diffuse textures in v2.0. Community mirrors at `mrbrz/Hunyuan3D-2.1` and `ddalcu/Hunyuan3D-2.1-MLX-Serve-8bit` (with auto-rigging via UniRig). Official Tencent HF org release pending.
- **VRAM note:** Full-precision texture synthesis ~14–20 GB; wait for official quantized weights before enabling on 16 GB hardware.
- **Action:** Download community mirror for evaluation; wait for official Tencent release + ComfyUI node update.
- **Source:** https://huggingface.co/mrbrz/Hunyuan3D-2.1

### 6. AnchorSplat — Gaussian Splat Detail Synthesis (Jul 3, ECCV 2026)
- **Affects:** `build_hunyuan_3d_mesh` (post-processing augment)
- **What changed:** Source-free end-to-end network operating directly on 3DGS assets; no original images needed. Claimed 10^5× faster than iterative densification. MIT license. Fits <6 GB VRAM. Would add a quality-enhancement step after HunYuan3D mesh generation.
- **Action:** New optional `build_hunyuan_3d_mesh_refined` builder wrapping AnchorSplat; or post-process step in the existing builder.
- **Source:** https://huggingface.co/de233/AnchorSplat-20x

### 7. SAM3.1 — Incremental SAM Update (ecosystem spike this week)
- **Affects:** `build_sam3_segment`, `build_sam3_mask`, `build_sam3_extract`
- **What changed:** `facebook/sam3.1` improves concept-prompt accuracy over SAM3. Ecosystem activity spiked this week: CoreML quant variant appeared Jun 29, Grounded-SAM3.1 space live Jul 6. Primary caveat: gated HF repo (access request required).
- **Action:** Request HF access; update base checkpoint path in SAM3 node calls once approved.
- **Source:** https://huggingface.co/facebook/sam3.1

### 8. FLUX.2-klein-9B Manga Colorization LoRA (Jul 6)
- **Affects:** `build_colorize` (augment for manga/flat-art inputs)
- **What changed:** Reference-controlled colorization LoRA on the Klein-9B backbone for manga/line-art — fills a gap in the current `build_colorize` which uses generic Klein prompting. Apache-2.0 license.
- **VRAM note:** Klein-9B base requires ~18 GB at fp16; needs fp8 or int4 quantization. Dependent on ComfyUI v0.27.0 int8 support (Tier 1 item #1) to fit 16 GB.
- **Action:** Integrate after ComfyUI v0.27.0 upgrade; requires quantized Klein-9B base.
- **Source:** https://huggingface.co/milo01/FLUX.2-klein-9B-manga-colorization-by-reference-LORA
