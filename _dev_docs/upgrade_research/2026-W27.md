## Tier 1 — Drop-in supersessions (ship soon)

These require no new builder methods and minimal risk. Recommend actioning within the next sprint.

### 1. ComfyUI v0.27.0 — native int8 engine *(affects all builders)*
Engine-level int8 quantization for every model loaded through ComfyUI. On a 16 GB card, Flux 12B and Klein 9B drop from ~18 GB to ~10–11 GB (int8), eliminating OOM risk on the RTX 5060 Ti. Also ships: `ConditioningMultiply` node (useful for ControlNet weighting), Krea-2 advanced merging, memory-leak fixes.
- **Action**: `pip install --upgrade comfyui` (or pull latest git) on the target machine.
- **Risk**: low. Additive engine feature; existing workflows load unchanged.

### 2. Boogu-Image-0.1-Edit-Turbo — 4-step image editor for `build_qwen_edit`
4-step DMD-distilled variant of the Boogu-Image editing family. Same architecture as what `build_qwen_edit` already targets (10B DiT + Qwen3-VL-8B text encoder + FLUX VAE), Apache-2.0 licensed, FP8 checkpoint fits 16 GB. Drops editing inference from ~50 steps to 4 at CFG ~1.0.
- **Action**: Download `Boogu/Boogu-Image-0.1-Edit-Turbo` FP8 checkpoint. Wire as a fast-path variant inside `build_qwen_edit` (or a new `build_qwen_edit_turbo`). Pin to FP8 quantized weights.
- **Risk**: medium — new model, limited community testing at survey time (13 downloads).

### 3. HyperSwap ONNX models via updated ReActor
ReActor's May 12 update (New ReActor Core) supports `hyperswap_1a/1b/1c_256.onnx` from FaceFusion Labs alongside the existing `inswapper_128.onnx`. No C++ build tools or InsightFace required anymore. Community reports sharper swaps on high-resolution targets compared to inswapper.
- **Action**: Download HyperSwap 256 ONNX models into `ComfyUI/models/hyperswap/`. Expose as additional `swap_model` option in `build_faceswap` and `build_faceswap_model`. Update any ReActor node version pinning.
- **Risk**: low — optional parallel model path; existing inswapper path unchanged.

## Tier 2 — Additive new builders (needs node-pack install)

These add new capability or builder methods not currently present in Spellcaster. Require local node-pack installs or new `build_*` functions.

### 1. Krea-2-Turbo → new `build_krea2_txt2img`
12B DiT post-trained with 2-step distillation. FP8 ~12 GB VRAM. ComfyUI native support since v0.26.0. Community License: free commercial for studios < 50 seats. Shares Qwen3-VL text encoder with Boogu-Image. 69.8K downloads in 9 days — strong community adoption.
- **Needs**: new `build_krea2_txt2img` builder; base `build_txt2img` should not be modified.
- **Risk**: medium — 12B model, needs FP8/GGUF at 16 GB; base (Krea-2-Raw) is BF16-only and out of budget.

### 2. Seedance 2.0 Mini + 4K → new `build_seedance_video`
ByteDance Partner Node (cloud API) in ComfyUI v0.26.2. T2V + First-Last-Frame + Reference modes. 4K resolution unlocked for standard tier. Zero local VRAM. Supersedes Seedance 1.5 Pro.
- **Needs**: new `build_seedance_video` builder mapping to the Partner Node API; requires Seedance API key in user config.
- **Risk**: low — cloud API, no hardware dependency.

### 3. Deno2026 LTX tiled sampler/upscaler → enhances `build_ltx_video`
Releases v0.7.63–v0.7.66 (Jun 26 – Jul 1) add: LTX AV Tiled Sampler (audio context across tiles), LTX Tiled Spatial Upscaler (overlapping tile latents), and an optional RTX Video Super Resolution wrapper. Enables LTX 2.3 22B at 16 GB via tiled sampling.
- **Needs**: install `Deno2026/comfyui-deno-custom-nodes` node pack on target machine. Wire tiled sampler node into `build_ltx_video` second pass.
- **Risk**: low.

### 4. Cameraman IC-LoRA v2.0 for LTX 2.3 → drop-in for `build_ltx_video`
Camera-motion IC-LoRA (not a style LoRA — drives camera trajectory). v2.0 released Jun 25 with expanded training set. Works with T2V and I2V modes. Standard LoRA slot in `build_ltx_video`.
- **Needs**: download LoRA checkpoint; expose `camera_lora` param in `build_ltx_video`.
- **Risk**: low.

### 5. Qwen3-VL-8B as optional Klein text encoder
ComfyUI v0.26.0 enables Qwen3-VL-8B as an optional text encoder for the entire Flux2 Klein family. Improves prompt adherence for complex compositional descriptions without touching the diffusion backbone.
- **Needs**: surface as opt-in parameter in `build_klein_*` methods; expose encoder path in preset config.
- **Risk**: low — purely additive; existing CLIP pairing unchanged by default.

### 6. BFS-Best-Face-Swap IC-LoRA (Qwen-Image-Edit-2511) → alternative for `build_faceswap_mtb`
Diffusion-native face/head swap via Qwen2.5 VL IC-LoRA adapter. Avoids per-frame ONNX artifacts common with inswapper on high-res stills. Tagged comfyui, klein, flux2. 10–12 GB VRAM.
- **Needs**: verify Qwen2.5 commercial license before shipping; expose as `method="qwen_ic"` variant in `build_faceswap_mtb` or as separate builder.
- **Risk**: medium — commercial license uncertainty.
