## Tier 1 — drop-in supersessions (ship soon)

### 1. SAM 3.1 → all three `build_sam3_*` methods

- **URL**: https://huggingface.co/facebook/sam3.1 — https://huggingface.co/Comfy-Org/sam3.1
- **Release**: 2026-03-27; Comfy-Org checkpoint published May 2026
- **Why ship**: Object Multiplex — ~7× faster multi-object tracking (128 objects simultaneously); open-vocabulary text + exemplar prompts; zero-shot mask AP 47.0 vs prior SOTA 38.5. Same ComfyUI node API — checkpoint swap only.
- **VRAM**: ~6–8 GB (unchanged vs SAM3)
- **Risk**: Low — official Comfy-Org packaging; non-commercial gated license (accept once on HF)
- **Action**: Download `Comfy-Org/sam3.1` checkpoint; update preset path in `build_sam3_segment` / `build_sam3_mask` / `build_sam3_extract`.

### 2. ReActor Core (no-InsightFace rebuild) → `build_faceswap`, `build_faceswap_model`, `build_face_restore`, `build_video_reactor`

- **URL**: https://github.com/Gourieff/ComfyUI-ReActor
- **Release**: ~May 2026; CPU-only HF Space created 2026-06-01 confirms active momentum
- **Why ship**: Drops hard C++ InsightFace build dependency; replaces face analyser with pure-Python equivalent. Adds Face Similarity QA node (post-swap likeness score). Adds GPEN-1024/2048 restoration model support. 10× speed-up on video frame analysis.
- **VRAM**: 4–6 GB (unchanged)
- **Risk**: Low — established maintainer (Gourieff); drop-in upgrade
- **Action**: Update ComfyUI-ReActor to latest tag; optionally add GPEN-1024 as restoration model option in `build_face_restore` preset.

## Tier 2 — additive new builders (needs node-pack install)

### 4. nvidia/PiD — unified decode+upscale → candidate new `build_pid_upscale`

- **URL**: https://huggingface.co/nvidia/PiD — paper: https://arxiv.org/abs/2605.23902 — ComfyUI node: https://github.com/Merserk/ComfyUI-PiD
- **Release**: Paper 2026-05-25; community ComfyUI-PiD node **~2026-06-02 (IN WINDOW)**
- **Why add**: Unifies latent decoding + 4×/8× SR in a single pixel-space diffusion step. 6× lower latency than cascaded (VAE decode → 4x-UltraSharp) pipeline. Works with Flux, SDXL, SD3 backbones. Staged VRAM-offload mode (Prepare → Sample → Finalize). NVIDIA Research (nv-tlabs) pedigree.
- **VRAM**: ~13 GB peak at 2048×2048
- **Risk**: Medium — community ComfyUI node (not official); novel architecture; requires workflow-level change vs current VAE→SR pipeline
- **Action**: Install `ComfyUI-PiD`; download nvidia/PiD weights; create `build_pid_upscale` or expose as a `decode_mode="pid"` option inside `build_upscale`. Validate on RTX 5060 Ti 16 GB with staged offload.
