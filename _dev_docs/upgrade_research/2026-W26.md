## Tier 1 — Drop-in supersessions (ship soon)

These replace existing backbones with clearly superior options that fit the 16 GB VRAM budget. No new node-pack installs required beyond existing ComfyUI setup.

### 1. LTX-2.3 → `build_ltx_video`
- **Release:** March 5, 2026 (Lightricks)
- **What changed:** 22B parameter model (14B video + 5B audio + 3B VAE); native 4K at 50 FPS; synchronized stereo audio; up to 20-second clips; fully open weights (Apache 2.0). The 8-step distilled variant with FP8 quantization fits 16 GB VRAM for 1080p output.
- **Action:** Swap checkpoint to `Lightricks/LTX-2.3` on HuggingFace. Update `build_ltx_video` to use the new model loader (ComfyUI v0.26.0 adds native `LTX2 Context Windows` node).
- **Refs:** https://github.com/Lightricks/LTX-Video · https://huggingface.co/Lightricks/LTX-2.3

### 2. HunyuanVideo 1.5 → `build_hunyuan_video`
- **Release:** November 2025 (Tencent)
- **What changed:** 8.3B parameters (down from 13B); Selective and Sliding Tile Attention (SSTA); bilingual text encoding. FP8 + CPU T5 offload runs on 16 GB VRAM.
- **Action:** Update checkpoint path to `tencent/HunyuanVideo-1.5`. Adjust VRAM settings for FP8.
- **Refs:** https://huggingface.co/tencent/HunyuanVideo-1.5 · https://github.com/Tencent-Hunyuan/HunyuanVideo-1.5

### 3. SAM 3.1 → `build_sam3_segment`, `build_sam3_mask`, `build_sam3_extract`, `build_magic_eraser`
- **Release:** March 27, 2026 (Meta)
- **What changed:** Object Multiplex — processes up to 16 objects in a single forward pass; 7× faster inference at 128 objects; 32 FPS throughput; zero accuracy loss versus SAM 3. Comfy-Org mirror at `Comfy-Org/sam3.1`.
- **Action:** Swap checkpoint to `facebook/sam3.1` (or `Comfy-Org/sam3.1`). No node changes required.
- **Refs:** https://huggingface.co/facebook/sam3.1 · https://docs.comfy.org/tutorials/utility/video-segment-sam3

### 4. Krea 2 Turbo → additive backbone for `build_txt2img`, `build_img2img`, `build_generate_anything`
- **Release:** June 22, 2026 (Krea)
- **What changed:** New 12B single-stream DiT with Qwen3-VL-4B text encoder and Krea's own VAE. FP8 Turbo variant (~12 GB) fits 16 GB with room for VAE. 8-step distilled (Turbo) or full quality (Raw). Community commercial license: free for individuals and teams ≤50 seats. Day-0 ComfyUI support (ComfyUI 0.26.0+). Strong aesthetic diversity and style fidelity.
- **Action:** Add Krea 2 Turbo as an architecture option (`krea2` arch entry). Requires ComfyUI ≥0.26.0. Weights at `krea/Krea-2-Turbo` (HF) or `Comfy-Org/Krea-2` for quantized.
- **Refs:** https://huggingface.co/krea/Krea-2-Turbo · https://blog.comfy.org/p/krea-2-open-source-models-are-now · https://www.krea.ai/blog/krea-2-technical-report

## Tier 2 — Additive new builders (needs node-pack install)

New capabilities not currently wired in spellcaster. Each requires installing a new ComfyUI node pack or updating an existing one.

### 5. Boogu-Image-0.1 Edit → new/replacement for `build_qwen_edit` (and `build_inpaint`)
- **Release:** June 16, 2026 base; June 24, 2026 hotfix (Boogu Project)
- **Summary:** 10B double-stream MMDiT + Qwen3-VL-8B encoder + FLUX.1 VAE. Three variants: Base (quality/diversity), Turbo (3-4 step, photorealism), Edit (instruction-based editing). Apache 2.0 license. Native ComfyUI support in v0.26.0 via `TextEncodeBooguEdit` node. Strong bilingual (Chinese-English) text rendering. Turbo hotfix (Jun 24) fixes aspect-ratio artifacts. 13 GB FP8 (~13 GB), NVFP4 ~8 GB.
- **Refs:** https://github.com/boogu-project/Boogu-Image · https://huggingface.co/Comfy-Org/Boogu-Image

### 6. comfyui-deno-custom-nodes v0.7.62 → extends `build_video_upscale`, `build_ltx_video`, `build_wan_video`
- **Release:** June 24, 2026 (Deno2026)
- **Summary:** RTX Video Super Resolution in ComfyUI using NVIDIA Tensor Cores (not diffusion). 4 modes: VSR (compressed source), High Bitrate, Denoise, Deblur. Single-pass and 2-pass options. Also includes: LTX 2.3 unified model loader (checkpoint/KJ/GGUF); LTX Multi LoRA Loader; LTX tiled spatial upscaler (beta); Wan 2.2 reference video editing; Video A/B compare slider; H.264 inline preview. Windows/NVIDIA RTX only — RTX 5060 Ti fully compatible.
- **Refs:** https://github.com/Deno2026/comfyui-deno-custom-nodes

### 7. LTX Director 2.0 → extends `build_ltx_video`
- **Release:** June 21, 2026 (WhatDreamsCost community)
- **Summary:** Full non-linear timeline editor layered over LTX-2.3 in ComfyUI. Adds: trim/split/extend/combine, IC-LoRA track drag-and-drop, Retake Mode (re-generate specific segments), Timeline Save/Load (JSON), sidebar UI, hotkeys, multi-select. Free/open-source. Works with I2V, T2V, FLF, Prompt Relay, custom audio.
- **Refs:** https://github.com/WhatDreamsCost/WhatDreamsCost-ComfyUI

### 8. HyperSwap 1a/1b/1c → upgrade path for `build_faceswap`, `build_faceswap_model`
- **Available via:** ComfyUI-ReActor v0.6.2 (April 25, 2026)
- **Summary:** Three quality tiers from FaceFusion Labs: 1a (speed), 1b (balanced), 1c (high quality). Higher fidelity than inswapper_128.onnx. Weights hosted at `facefusion/models-3.3.0` on HuggingFace. ReActor v0.6.2 also adds `Restore Face Advanced` node (selectively restores only swapped faces). Estimated 4-6 GB VRAM.
- **Refs:** https://github.com/Gourieff/ComfyUI-ReActor · https://huggingface.co/facefusion/models-3.3.0

### 9. ComfyUI-TBG-ETUR v1.2.11 → extends `build_detail_hallucinate`, `build_supir`
- **Release:** June 13, 2026 (Ltamann — just outside 7-day window)
- **Summary:** Tiled upscaler/refiner for ComfyUI. New in v1.2.11: NVIDIA PiD as dedicated tiled upscaler; Flux 2 / Flux 2 Klein upscaling harness; per-tile CFG/model/ControlNet overrides; Neuro-Generative Tile Fusion (seamless joins); batch processing with VRAM efficiency; tile-aware color correction; geometry drift correction. Processes images up to 200MP. Low Memory Mode saves 4-10 GB. Install via ComfyUI Manager (search 'TBG').
- **Refs:** https://github.com/Ltamann/ComfyUI-TBG-ETUR

## Tier 3 — Monitor / not wire-ready

### 10. OmniGen2
- **Release:** June 23, 2026 (BAAI)
- **Why not Tier 2:** 17 GB baseline VRAM; CPU offload drops GPU to ~6 GB but degrades throughput significantly. Needs FP8/NVFP4 quantized variants before production use on 16 GB.
- **Relevance:** `build_qwen_edit`, `build_img2img` — unified multimodal instruction editing (clothing swap, pose change, background change, in-context reference)
- **Refs:** https://huggingface.co/BAAI/OmniGen2 · https://arxiv.org/abs/2506.18871 · https://github.com/VectorSpaceLab/OmniGen2

### 11. Wan 2.7 (open weights on ModelScope)
- **Release:** April 22, 2026 (Alibaba Wan-AI)
- **Why Tier 3:** GGUF quantized variants + CPU offload may fit 16 GB but are not confirmed; weights on ModelScope only (not HF); ComfyUI integration needs testing. Series naming: 2.1 → 2.2 → 2.7 (no 2.3 exists).
- **Relevance:** `build_wan_video`, `build_wan22_t2v`, `build_wan_flf` — 1080p, 15-20s, native audio, instruction editing, multi-reference
- **Refs:** https://github.com/Wan-Video/Wan2.2 (upstream) · ModelScope: Wan-AI org

### 12. Sapiens2 (0.4B)
- **Release:** April 27, 2026 (Meta, ICLR 2026)
- **Why Tier 3:** No ComfyUI node yet; primarily human-centric (not general scene normals)
- **Relevance:** `build_normal_map`, `build_sam3_segment` — 4 sizes (0.4B–5B); tasks: pose, body-part seg, surface normals, pointmaps, albedo. 0.4B fits 16 GB.
- **Refs:** https://github.com/facebookresearch/sapiens2 · https://huggingface.co/facebook/sapiens2 · https://arxiv.org/abs/2604.21681

### 13. Hunyuan3D-Omni
- **Release:** September 2025 (Tencent)
- **Why Tier 3:** No ComfyUI node yet; spellcaster integration requires a new builder
- **Relevance:** `build_hunyuan_3d_mesh`, `build_hunyuan_3d_textured` — 'ControlNet of 3D'; inputs: bbox/pose/point cloud/voxel; 10 GB VRAM (fits 16 GB)
- **Refs:** https://huggingface.co/tencent/Hunyuan3D-Omni · https://github.com/Tencent-Hunyuan/Hunyuan3D-Omni

### 14. ColorFLUX (CVPR 2026)
- **Release:** Paper only; no public weights as of Jun 26 2026
- **Why Tier 3:** Weights not released
- **Relevance:** `build_ddcolor` — FLUX-based colorizer; eliminates old-photo color bias via progressive DPO; structure-color decoupling
- **Refs:** https://arxiv.org/abs/2603.28162

### 15. LTX Trainer unified (13 training modes)
- **Release:** June 17, 2026 (Lightricks)
- **Why Tier 3:** Training tool, not an inference upgrade; enables IC-LoRA / character LoRA creation for `build_ltx_video`
- **Refs:** https://github.com/Lightricks/LTX-2 · https://gigazine.net/gsc_news/en/20260618-ltx-trainer-video-generation-ai-lora/

### 16. HiWave (arXiv, Jun 25 2026)
- **Release:** Paper only; no code released
- **Why Tier 3:** No code yet
- **Relevance:** `build_txt2img`, `build_img2img` — training-free high-resolution boost via wavelet-based detail enhancement; works with existing SDXL/Flux models; ETH Zurich + Disney Research; SIGGRAPH Asia 2025
- **Refs:** https://arxiv.org/abs/2506.20452

### 17. HY-World 2.0
- **Release:** April 16, 2026 (Tencent)
- **Why Tier 3:** Full pipeline VRAM likely prohibitive for RTX 5060 Ti 16 GB; navigable world-scale 3D is a different scope than current `build_hunyuan_3d_*`
- **Refs:** https://github.com/Tencent-Hunyuan/HY-World-2.0

### 18. InfiniDepth (CVPR 2026)
- **Release:** March 2026 (ZJU-3DV)
- **Why Tier 3:** No ComfyUI node; specializes in arbitrary-resolution single-image depth — complements DA3 rather than replacing it
- **Relevance:** `build_depth_map_v3` extension
- **Refs:** https://github.com/zju3dv/InfiniDepth · https://huggingface.co/papers/2601.03252

### 19. NVIDIA Cosmos 3 (Nano / Super) — SKIP-VRAM
- **Release:** June 22, 2026 (NVIDIA)
- **VRAM:** Cosmos3-Nano = ~32 GB BF16; Super = 80GB×8. NOT viable on RTX 5060 Ti 16 GB.
- **Refs:** https://huggingface.co/nvidia/Cosmos3-Nano

### 20. FLUX.2 dev FP8 — SKIP-VRAM
- **Note:** 32B parameters; even GGUF Q4 (~19 GB) exceeds 16 GB budget. Klein 4B/9B remains the viable Flux2 branch for 16 GB.
- **Refs:** https://blogs.nvidia.com/blog/rtx-ai-garage-flux-2-comfyui/

## Tier 2 (additive) — Notable near-misses (just outside 7-day window, high relevance)

### Ideogram 4.0 (June 3, 2026)
- 9.3B single-stream DiT; Qwen3-VL-8B text encoder; best-in-class text rendering; non-commercial license; FP8 fits 16 GB; day-0 ComfyUI. Just 2.5 weeks old — worth evaluating alongside Krea 2 and Boogu-Image as a text-rendering-focused backbone option.

- **Refs:** https://github.com/deepinsight/insightface

- **Refs:** https://github.com/Comfy-Org/ComfyUI/pull/14009
