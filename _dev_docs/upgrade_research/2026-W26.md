## Tier 1 — drop-in supersessions (ship soon)

### 1. Moebius 0.22B Lightweight Inpainting (ECCV 2026)

- **Affects:** `build_inpaint`, `build_outpaint`, `build_magic_eraser`, `build_lama_remove`
- **Source:** https://huggingface.co/hustvl/Moebius · https://github.com/hustvl/Moebius
- **Paper:** https://huggingface.co/papers/2606.19195
- **Why ship:** 226 M parameters vs 11.9B (FLUX.1-Fill-Dev); 26 ms/step on a single GPU; claims parity or better on inpainting benchmarks; MIT license; diffusers-compatible; ONNX export available (`simonw/Moebius-ONNX`); Spaces demo live (`multimodalart/Moebius`); Simon Willison blog verified 2026-06-22.
- **Action needed on local machine:** Add a `MoebiusInpainting` loader or expose as an architecture option inside `build_inpaint`. No new custom-node pack required — uses the standard diffusers library.

### 2. Qwen-Image-Edit 20B (Alibaba, open-source 2026-06-25)

- **Affects:** `build_qwen_edit`
- **Source:** https://huggingface.co/Qwen/Qwen-Image-Edit · https://github.com/QwenLM/Qwen-Image
- **Why ship:** Direct architectural target for `build_qwen_edit`. Open-sourced by Alibaba Tongyi on 2026-06-25. Uses Qwen2.5-VL as condition encoder + VAE Encoder for appearance preservation. Supports semantic edits, object add/remove, colour/tone, bilingual text rewriting. Available on HuggingFace and ModelScope.
- **Action needed on local machine:** Update default model names in `build_qwen_edit`. May need int8 quantisation to fit 20B on 16 GB VRAM.

## Tier 2 — additive new builders (needs node-pack install)

### 3. Krea 2 Turbo + Raw (open weights 2026-06-22)

- **New builder candidate:** `build_krea2_txt2img` (or architecture extension to `build_txt2img`)
- **Source:** https://blog.comfy.org/p/krea-2-open-source-models-are-now · https://docs.comfy.org/tutorials/image/krea/krea-2
- **Details:** 12B dense DiT; Qwen3-VL text encoder + Qwen Image VAE. Krea 2 Turbo = 8-step distilled, ~2 K images in ~2 s. FP8 recommended for 16 GB GPU. **Requires ComfyUI ≥ 0.26.0.** License: proprietary community (commercial use free for entities < $1M revenue; enterprise licence above that).

### 4. Boogu-Image + TextEncodeBooguEdit (2026-06-23, native in ComfyUI v0.26.0)

- **New builder candidate:** `build_boogu_edit` or extension of `build_qwen_edit`
- **Source:** https://comfyui.org/en/boogu-image
- **Details:** Qwen3-VL-8B encoder + FLUX.1 VAE; double-stream MMDiT. `TextEncodeBooguEdit` node supports negative prompts + optional reference images. Bilingual Chinese/English. Three variants: base, edit, turbo. Included natively in ComfyUI ≥ 0.26.0; no separate node-pack install.

### 5. HyperSwap 1a/1b/1c_256.onnx via ComfyUI-ReActor ≥ 0.6.x (2026-05-12)

- **Upgrade path:** `build_faceswap`, `build_faceswap_model`, `build_faceswap_mtb`
- **Source:** https://github.com/Gourieff/ComfyUI-ReActor · https://huggingface.co/facefusion/models-3.3.0
- **Details:** Three-variant 256×256 ONNX face swap models (1a = speed, 1b = balanced, 1c = quality). 2× the resolution of inswapper_128. Models go in `ComfyUI/models/hyperswap/`. Also adds `ReActorSetWeight` per-face swap strength control. Additive — inswapper_128 still available and unchanged.

### 6. LTX-Video-0.9.8-13B-distilled + ICLoRAs (checkpoint 2025-07-17, ComfyUI-LTXVideo updated 2026-05)

- **Upgrade path:** `build_ltx_video`
- **Source:** https://huggingface.co/Lightricks/LTX-Video-0.9.8-13B-distilled
- **Details:** 13B distilled model (6× parameter count vs 2B predecessor). Supports up to 60-second videos. Companion ICLoRAs for detail enhancement, pose, canny edges, depth at v0.9.8. 165K downloads on the detailer ICLoRA. `ComfyUI-LTXVideo` node last updated May 2026.

### 7. ComfyUI-SeedVR2 1-Click v1.8b (2026-06-14)

- **Upgrade path:** `build_seedvr2_video_upscale`, `build_seedv2r`
- **Source:** https://github.com/numz/ComfyUI-SeedVR2_VideoUpscaler
- **Details:** New 1-Click GUI; FP8/GGUF support; BlockSwap for 8 GB VRAM. SeedVR2.5 backbone (ICLR 2026 accepted). A "full version" release was promised by the maintainer and may land this week. Pin check and regression test needed.
