## Tier 1 — Drop-in supersessions (ship soon)

Items confirmed available, low risk, 16 GB safe:

1. **HyperSwap 256 ONNX** (`hyperswap_1c_256.onnx` from `facefusion/models-3.3.0`) → `build_faceswap`. Download to `ComfyUI/models/hyperswap/`. 2× face region resolution over inswapper_128. ReActor issue #143 tracking native support.

2. **GPEN-2048 + facerestore_advanced node** (`flickleafy/facerestore_advanced`) → `build_face_restore`, `build_photo_restore`. Multi-model QA wrapper with CodeFormer/GFPGAN/GPEN fallback chain. Drop-in over facerestore_cf node.

3. **LTX Unified Trainer** (`Lightricks/LTX-2`, released **Jun 17**) → `build_ltx_video`. Enables LoRA/IC-LoRA custom variants. Inference pipeline unchanged.

4. **LTX-Video GGUF** (`RHB56/LTX-Video-gguf`, released **Jun 16**) → `build_ltx_video`. Lower VRAM path; compatible with kijai/ComfyUI-GGUF.

5. **SAM 3.1** (`facebookresearch/sam3`, Mar 2026) → `build_sam3_segment`, `build_sam3_mask`, `build_sam3_extract`. 50% VRAM reduction (~4 GB FP16), better accuracy. Check if spellcaster already pins 3.1 weights.

6. **NVIDIA RTX Nodes** (`Comfy-Org/Nvidia_RTX_Nodes_ComfyUI`) → `build_video_upscale`, `build_upscale`, `build_wavespeed_upscale`, `build_upscale_blend`. Zero weight download; hardware-native RTX VSR on RTX 5060 Ti; install via ComfyUI Manager.

7. **FLUX.2-small-decoder** (`black-forest-labs/FLUX.2-small-decoder`) → all `build_klein_*`. Reduces Klein VAE decode VRAM ~30%. Swap only the decoder.

8. **InstaPic Ultrareal LoRA** (Civitai, released **Jun 12**) → all `build_klein_*`. Photorealism LoRA for Klein 9B (ZIT variant); hot-swap via existing LoRA injection.

9. **DA3 weight check** (`depth-anything/DA3-LARGE`) → `build_depth_map_v3`. Low-effort verification: confirm spellcaster loads DA3 not DA2. If DA2, swap is 1-line config change.

10. **ComfyUI 0.23.0 MediaPipe face detection** (released Jun 1, now core) → `build_faceswap`, `build_klein_headswap`, `build_klein_face_detail`, `build_photobooth`. 478-landmark model in ComfyUI core, no extra Python dep. Update ComfyUI.
