## Tier 1 — Drop-in supersessions (ship soon)

### 1. DicFace → `build_face_restore`, `build_photo_restore`
- **What**: Replaces CodeFormer with a Dirichlet-continuous VQ-VAE codebook. Spatio-temporal Transformer eliminates inter-frame flicker.
- **Why**: CodeFormer is a discrete hard-lookup codebook; DicFace's probabilistic transitions give smoother results across sequential frames (photobooth, multi-frame portrait pipelines).
- **How**: GitHub release at https://github.com/fudan-generative-vision/DicFace. Weights available. Needs a wrapper replacing the CodeFormer inference call in the ComfyUI node chain.
- **VRAM**: ~8-12 GB (comparable to CodeFormer + RAFT scale). ✅ Fits 16 GB.
- **Risk**: Low. Architecture is self-contained; inference API is analogous to CodeFormer.

### 2. DA3-LARGE-1.1 checkpoint → `build_depth_map_v3`, `build_normal_map`
- **What**: Drop-in checkpoint upgrade. DA3-LARGE-1.1 is an improved iteration of DA3-LARGE.
- **Why**: Apache 2.0 license vs CC-BY-NC-4.0 (commercial-safe). Improved accuracy per -1.1 designation. GGUF packaging (Jun 15) enables CPU-offload inference option.
- **How**: Change the model filename from `da3_large.safetensors` to the -1.1 variant. Same inference pipeline.
- **VRAM**: ~4-6 GB. ✅ Fits comfortably.
- **Risk**: Low. Same Depth Anything 3 family, same ComfyUI nodes.

### 3. Promote SeedVR2 → `build_seedvr2_video_upscale`
- **What**: Unarchive the dormant `scaffold/workflows/_archived_R135/seedvr2_video_upscale.json`. Comfy-Org now publishes official SeedVR2 weights (ByteDance-Seed/SeedVR2-3B).
- **Why**: Model is live, Comfy-Org weights are official, mxfp8/nvfp4 quantizations exist. One-step adversarial inference is ~10-20x faster than multi-step diffusion upscalers. The builder references `SeedVR2LoadVAEModel` which is the correct node class.
- **How**: Move workflow out of archive, wire up `build_seedvr2_video_upscale` in workflows.py (it already exists as a function).
- **VRAM**: 3B at mxfp8 fits well within 16 GB. ✅
- **Risk**: Low. Archived workflow already validated structure.

## Tier 2 — Additive new builders (needs node-pack install)

### 4. SCAIL-2 → new `build_scail2_character_animate`
- **What**: Pose-driven, cross-identity character animation. Feeds a pose video + identity image → output video of target identity performing the motion.
- **Source**: https://hf.co/Comfy-Org/SCAIL-2 (official Comfy-Org weights, MIT license). GGUF quant at `vantagewithai/SCAIL-2-GGUF-ComfyUI` (6.5K downloads in ~10 days).
- **Capability gap**: Spellcaster has no "reanimate a stock video as a specific person" primitive. Relevant to Masquerade/Animancer characters.
- **VRAM**: Unconfirmed; expect 12-16 GB for full model. GGUF variant may run lower.
- **Risk**: Low. Official weights, MIT license. Node class names to verify against ComfyUI-Manager index.

### 5. DLoRAL → new `build_video_upscale_dloral` (or extend `build_video_upscale`)
- **What**: Dual-LoRA one-step SD-based video super-resolution. Two LoRA branches (cross-frame consistency + spatial detail) merged at inference.
- **Source**: https://hf.co/papers/2506.15591 + https://github.com/yjsunnn/DLoRAL (weights available Jun 18).
- **Why**: Single inference step, trained jointly for temporal coherence and spatial detail. Outperforms prior SD-based VSR methods.
- **Caveat**: SD backbone version (SD1.5 vs XL) not confirmed from paper alone. Verify before integrating; VRAM estimate is ~8-12 GB.
- **Risk**: Medium. Brand-new (Jun 18), no community validation on RTX 5060 Ti yet.

### 6. Wan2.2 Lightning + Animate extensions → extend `build_wan_video`
- **What**: Two new checkpoint variants for WAN 2.2: (a) Lightning I2V (~8 steps vs 20-40), (b) Animate (nvfp4, motion-guided I2V).
- **Sources**: Lightning — https://hf.co/laoK888/wan2.2_14b_i2v_480p_lightning_nsfw_diffusers; Animate — https://hf.co/LHQAQ-Li/wan2.2_animate_14b_fp16_nvfp4_comfy_V2
- **How**: Add `lightning_steps` param defaulting to 8 when a Lightning checkpoint is detected; add `build_wan_animate` builder for the Animate variant (new parameter: `motion_video_filename`).
- **Risk**: Low. Community quantizations of official Wan-AI/Wan2.2 checkpoints.

### 7. HSA inference acceleration → wrap `build_wan_video`, `build_ltx_video`
- **What**: Training-free heterogeneous step allocation for DiT video models. Routes different token budgets to different spatiotemporal positions. 2-4x speedup on WAN-2 and LTX-2 with minimal quality loss.
- **Source**: https://hf.co/papers/2605.06892 (paper May 2026, code at https://ernestchu.github.io/hsa).
- **How**: Inference wrapper layer; no model weight change. Same VRAM as base model.
- **Risk**: Low. Training-free, non-destructive. Step budget is configurable so conservative settings are safe.
- **Note**: ⌚ Outside 7-day window (May 7), but directly targets spellcaster's WAN/LTX stack.
