## Tier 1 — drop-in supersessions (ship soon)

These require only a config/checkpoint update or a node upgrade — no new builder needed.

### 1. Bernini-R conditioning for `build_wan22_t2v`
**What**: ByteDance's Bernini-R adds source-id RoPE + stream-concatenation modes to the existing `Wan2.2-T2V-A14B` weights (structurally identical, new conditioning branch). Enables Reference-to-Video (R2V), Video-to-Video (V2V), and Reference+Video-to-Video (RV2V) — frame-guided editing not previously possible with the T2V builder.
**How to integrate**: Install `ComfyUI-BerniniR` node pack (or rely on ComfyUI v0.25.0 native support). Use GGUF Q8 or blockswap on the existing WAN2.2 checkpoint to stay within 16 GB.

### 2. `one-node-flux-2-klein` node for `build_klein_headswap`
**What**: A new ComfyUI custom node (June 18-20, 2026) that consolidates the Klein Flux2 face/head-swap pipeline — model loading, BFS LoRA application, and sampling — into a single widget with a dedicated FACESWAP mode. Latest update (June 19) adds external model loader + GGUF; June 20 adds negative LoRA strength.
**How to integrate**: Install `yanokusnir-ai/one-node-flux-2-klein`; update `build_klein_headswap` to emit this node instead of the multi-node Klein sampler chain. Use 4B variant (~8 GB) or 9B FP8 (~14-16 GB).

### 3. BFS-Best-Face-Swap LoRA as default face-swap for Klein builders
**What**: `bfs_head_v1_flux-klein_4b.safetensors` and `_9b.safetensors` (Alissonerdx, MIT, 396K downloads). The community's dominant diffusion-native face-swap LoRA for Flux 2 Klein — replaces inswapper ONNX for Klein workflows.
**How to integrate**: Wire into `build_klein_headswap` and `build_klein_face_detail` as the default LoRA. Both fit within 16 GB (4B ~8 GB, 9B FP8 ~14-16 GB).

### 4. Depth Anything 3 native nodes for `build_depth_map_v3`
**What**: ComfyUI v0.25.0 (June 16) ships native DA3 nodes. If Spellcaster currently calls a third-party custom node wrapper, this native integration should be cleaner.
**How to integrate**: Update ComfyUI to v0.25.0+; switch `build_depth_map_v3` to use the core DA3 node. DA3-Large (~8 GB) is the recommended quality/VRAM tradeoff. Note CC BY-NC 4.0 license.

### 5. SAM 3.1 checkpoints for `build_sam3_*` builders
**What**: SAM 3.1 adds the Object Multiplex capability for joint multi-object video tracking without per-object accuracy loss. In ComfyUI core (PR #13408, April 23). Multiple wrapper suites updated.
**How to integrate**: Confirm the running checkpoint is SAM 3.1, not the SAM3-base preprint. All three builders (`build_sam3_segment`, `build_sam3_mask`, `build_sam3_extract`) benefit.

### 6. SeedVR2 ICLR-final checkpoint for `build_seedv2r` / `build_seedvr2_video_upscale`
**What**: ICLR 2026 final weights are the authoritative release for SeedVR2. The June 2026 arXiv revision (2506.05301v2) documents the final model.
**How to integrate**: Verify checkpoint path in both builders points to ICLR-final weights (`numz/ComfyUI-SeedVR2_VideoUpscaler`), not earlier preprint weights.

## Tier 3 — monitor / not wire-ready

- **NVIDIA PixelDiT-1300M** — CVPR 2026 Best Paper Finalist. Novel pixel-space architecture (no VAE), GenEval 0.74 (below Flux2). ComfyUI native support in v0.25.0 via PiD nodes. Not a Flux/SDXL replacement today but an emerging architecture worth tracking for a potential `build_pixeldit_txt2img` builder. VRAM: feasible at 1.3B params.
- **Wan 2.7** — API-released (April 2026), 1080p/15s/native audio. Community GGUFs exist on HF but no official open weights confirmed. Watch `Wan-AI` HuggingFace org.
- **Wan 3.0** — Announced ~June 19, 60B MoE (14B active), 4K/30s. Zero confirmed weights on Wan-Video GitHub or Wan-AI HF org. Multiple SEO sources cite release but GitHub shows no Wan3 repo. **Do not build against this** — treat as unconfirmed rumor.
- **RTX Video Super Resolution** — Hardware-accelerated 4K upscale in `comfyui-deno-custom-nodes v0.7.51` (June 19). NVIDIA RTX 50xx only, Windows only. Very fast; no diffusion overhead. If Spellcaster deploys on NVIDIA RTX 50xx Windows users, this is a meaningful alternative to SeedVR2. Platform-constrained.
- **LiTo** (Apple, ICLR 2026, Gaussian Splat with light fields) — ComfyUI wrapper exists (`PozzettiAndrea/ComfyUI-LiTo`). Novel-view synthesis rather than mesh. VRAM unknown at 16 GB; no community reports yet.
- **InfiniteYou** (ByteDance, ICCV 2025) — Excellent identity preservation with FLUX DiT. ⚠️ 43 GB BF16 / 24 GB FP8 — hard budget bust. No GGUF path confirmed. Revisit if quantized.
- **CodeFormer++** — Oct 2025 paper, outperforms CodeFormer on FID/LPIPS/NIQE. No public weights as of June 20. Watch `sczhou/CodeFormer`.
- **RealRestorer** — Multi-degradation (blur/noise/haze/rain/reflection) restoration. ⚠️ ~34 GB VRAM at 1024px. Tiling workaround needed. Revisit for 16 GB once ComfyUI tiling node is confirmed.
- **FiDeSR** — CVPR 2026 accept, 1-step diffusion SR. Code not yet released. Monitor.
- **Code2Collapse CustomNodePacks v1.30.4** (May 2026) — 72-node production VFX suite: LUT + SAM3 + MatAnyone2 + BiRefNet alpha matting + EXR I/O. Single dependency potentially consolidating several Spellcaster builders; worth evaluating as a runtime dependency reduction.
- **ZImage-i2L-v2** — Image-to-LoRA V2 for Z-Image (DiffSynth, June 15-17). Z-Image not currently in Spellcaster's builder stack; monitor if a `build_zimage_txt2img` builder is planned.
