## Tier 2 — additive new builders (needs node-pack install)

These items require new node-packs, custom wrappers, or new builder methods. No production deploy without local install + test.

1. **SCAIL-2** — `build_wan_animate_video` upgrade path. End-to-end character animation / motion transfer, no skeleton. Released **Jun 13 2026**. GitHub: `zai-org/SCAIL-2`. ComfyUI workflow: nextdiffusion.ai Jun 11. GGUF variant at `realrebelai/SCAIL-2_GGUF` fits 16 GB. New builder suggested: `build_scail2_animate`.

2. **FlashVSR** — additive `build_video_upscale` path. One-step diffusion streaming VSR. CVPR 2026. ComfyUI node: `1038lab/ComfyUI-FlashVSR`. Tiling mode + sparse_sage_attention fits 16 GB. Better detail than ESRGAN, slower per frame. New builder or parallel path in `build_video_upscale`.

3. **Microsoft Lens (3.8 B)** — new lightweight T2I builder slot. Apache-2.0. Native ComfyUI v0.23.0. `Comfy-Org/Lens` packaged weights. Turbo distilled available. Extremely VRAM-friendly. Suggest `build_lens_txt2img`.

4. **NVIDIA PixelDiT (1.3 B)** — new VAE-free pixel-space T2I builder. CVPR 2026 finalist. Native ComfyUI v0.23.0. `Comfy-Org/PixelDiT` packaged weights. 1.3 B, trivially fits 16 GB. Suggest `build_pixeldit_txt2img`.

5. **PiD decoder (ComfyUI-PiD)** — drop-in decode upgrade for SDXL and Qwen-Image builders. Unifies VAE decode + upscale into one conditional pixel-diffusion pass. ComfyUI v0.24.0. Additive, no new builder needed — insert into existing decode stage.

6. **FLUX.2 Klein 9B-KV** — `build_klein_*` multi-reference speedup. ~2.5× faster via KV-cache. `black-forest-labs/FLUX.2-klein-9b-kv` (FP8 ~18 GB — needs GGUF Q4 for 16 GB ⚠️VRAM). Suggest evaluating GGUF Q4 before wiring.

7. **BFS Head Swap V1–V5 LoRAs** — Klein 9B LoRA series for `build_klein_headswap`. Better anatomical consistency and expression transfer. `Alissonerdx/BFS-Best-Face-Swap`. MIT license. Additive alongside existing headswap.

8. **BFS Best Face Swap LoRA** — instruction-following face swap via Klein 9B / Qwen-Image-Edit-2511. **Created Jun 17 2026** (in-window). `justusgeorge10/BFS-Best-Face-Swap`. New paradigm vs. GAN-based inswapper — no landmarks needed. Additive capability for `build_faceswap`. 12–14 GB VRAM.

9. **OSDFace** — `build_face_restore` upgrade. Single-step diffusion; beats CodeFormer on all metrics. CVPR 2025. `jkwang28/OSDFace`. No ComfyUI node yet — needs thin Python wrapper around the inference script. NTIRE 2026 validated.

10. **HunyuanWorld-Mirror (ICML 2026)** — new 3D pipeline that unifies depth + normals + 3D Gaussians in one pass. ComfyUI node: `cedarconnor/ComfyUI-HunyuanWorld-Mirror` (11 nodes). Complements `build_hunyuan_3d_mesh` and could absorb `build_depth_map_v3` / `build_normal_map` in a unified pass. Verify 16 GB VRAM before wiring.

11. **InfiniDepth (CVPR 2026)** — `build_depth_map_v3` upgrade. Arbitrary-resolution depth via neural implicit fields. `zju3dv/InfiniDepth`. No ComfyUI node yet — needs wrapping. Potentially superior to Depth Anything v3 at high res.

12. **LBM_normals (ICCV 2025 Highlight)** — `build_normal_map` upgrade. Single-step SOTA via latent bridge matching. `jasperai/LBM_normals`. Diffusers-compatible; no ComfyUI node yet. Low compute, fits 16 GB.
