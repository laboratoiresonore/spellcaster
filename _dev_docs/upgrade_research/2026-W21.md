## Tier 1 — Drop-in supersessions (ship soon)

### 1. HiDream-O1-Image-Dev FP8 — new txt2img/img2img backbone
- **Methods:** `build_txt2img`, `build_img2img` (as new alternative backbone, not replacement for Klein presets)
- **Model:** HiDream-O1-Image + Dev distilled variant
- **Source:** https://huggingface.co/Comfy-Org/HiDream-O1-Image / https://huggingface.co/drbaph/HiDream-O1-Image-FP8
- **ComfyUI:** Native workflow at `docs.comfy.org/tutorials/image/hidream/hidream-o1`; community node `Saganaki22/HiDream_O1-ComfyUI`
- **Release:** 2026-05-08 (base + Dev); FP8 community forks 2026-05-19 to 2026-05-22
- **VRAM:** ~10 GB FP8 (well within 16 GB)
- **License:** MIT
- **Why:** 8B pixel-space unified transformer. Handles txt2img, img2img, subject-driven personalization, storyboard, long text rendering. Internal reasoning-driven prompt expansion. Competes with FLUX.2 56B on benchmarks (WaveSpeed eval). No VAE/CLIP dependency. Dev variant: 28 steps, CFG 0.0, ~2× faster.
- **Action:** Install FP8 weights + native ComfyUI nodes. Wire new `build_hidream_txt2img` builder alongside existing presets — do NOT replace Klein; offer as an alternative backbone for non-Klein-specific workflows.

### 2. ComfyUI Native BiRefNet loader — simplification for `build_rembg_birefnet`
- **Method:** `build_rembg_birefnet`
- **Model:** BiRefNet-general (unchanged weights)
- **Source:** https://blog.comfy.org/p/new-open-source-models-now-in-comfyui
- **Release:** 2026-05-14 (ComfyUI native integration)
- **VRAM:** Same as current
- **Why:** ComfyUI now loads BiRefNet natively without the community custom node. Reduces a dependency. No quality change.
- **Action:** Switch `build_rembg_birefnet` to native BiRefNet loader node once ComfyUI is updated to the version that includes this (v0.21+ per changelog).

## Tier 2 — Additive new builders (needs node-pack install)

### 3. HyperSwap models via ReActor — additive face swap quality improvement
- **Methods:** `build_faceswap`, `build_faceswap_model`
- **Model:** hyperswap_1a_256.onnx, hyperswap_1b_256.onnx, hyperswap_1c_256.onnx (FaceFusion Labs)
- **Source:** https://github.com/Gourieff/ComfyUI-ReActor
- **Release:** Integrated into ComfyUI-ReActor (date unconfirmed, found in current docs)
- **VRAM:** Minimal (ONNX inference)
- **Why:** No longer requires InsightFace or C++ Build Tools. HyperSwap models achieve slightly higher cosine similarity than inswapper_128. New "Face Similarity" node for post-swap QC. Additive — existing inswapper_128.onnx still works.
- **Action:** Download hyperswap_1a/1b/1c_256.onnx to `ComfyUI/models/hyperswap/`. Update `build_faceswap` to expose `swap_model` option for HyperSwap. Test cosine similarity delta vs inswapper_128.

### 4. FlashVSR v1.1 — CVPR 2026 video super-resolution
- **Methods:** `build_video_upscale`, `build_seedvr2_video_upscale`
- **Model:** FlashVSR (one-step diffusion streaming VSR, 2x/4x)
- **Source:** https://github.com/OpenImagingLab/FlashVSR / https://huggingface.co/1038lab/FlashVSR
- **Release:** v1.1 November 2025; CVPR 2026 paper accepted
- **VRAM:** ~16 GB estimated (streaming locality-constrained sparse attention, designed for real-time)
- **License:** Apache 2.0
- **Why:** Peer-reviewed CVPR 2026. One-step diffusion (similar profile to SeedVR2). Auto-downloads weights from HF. Multiple community ComfyUI nodes (1038lab, smthemex, naxci1). 2x and 4x upscale supported.
- **Action:** Install `ComfyUI-FlashVSR` node pack. Add `build_flashvsr_upscale` builder. Keep `build_seedvr2_video_upscale` as fallback; offer FlashVSR as alternative upscale path.

### 5. NVIDIA RTX VSR — on-chip tensor core video upscale
- **Methods:** `build_upscale`, `build_upscale_blend`, `build_video_upscale`
- **Model:** NVIDIA RTX Video Super Resolution (Tensor Core path)
- **Source:** https://github.com/Comfy-Org/Nvidia_RTX_Nodes_ComfyUI
- **Release:** GDC 2026 (official Comfy-Org node)
- **VRAM:** Minimal additional (dedicated Tensor Core path, not occupying main VRAM budget)
- **License:** NVIDIA (proprietary but free-to-use on RTX hardware)
- **Why:** On RTX 5060 Ti, this uses dedicated hardware acceleration — claimed 30x faster than diffusion upscalers. Best for artifact reduction vs diffusion detail-hallucination. Complements rather than replaces SUPIR/SeedVR2. Official Comfy-Org integration.
- **Action:** Install `Nvidia_RTX_Nodes_ComfyUI`. Add fast-path option to `build_upscale` using RTX VSR node when running on RTX hardware.
