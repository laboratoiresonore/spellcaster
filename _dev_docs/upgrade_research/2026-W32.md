## Tier 1 — Drop-in supersessions (ship soon)

These require only a checkpoint download or minor node update — no workflow rework.

### 1. All build_klein_* (15 builders) — FLUX.2 FP8 RTX checkpoint

**Source:** NVIDIA RTX AI Garage blog (Aug 6, 2026): https://blogs.nvidia.com/blog/rtx-ai-garage-flux-2-comfyui  
**Action:** Download the Klein 9B FP8 checkpoint from Black Forest Labs / NVIDIA. Select `fp8_e4m3fn` precision in ComfyUI's `Load Diffusion Model` node.  
**Impact:** Klein 9B FP8 lands at ~15 GB — fits the RTX 5060 Ti 16 GB with 1 GB headroom. Klein 4B FP8 ~8 GB. 40% VRAM reduction, 40% throughput gain vs BF16. Pure precision upgrade; model behaviour identical.  
**Risk:** Low — checkpoint drop-in, no node changes.

### 2. build_ltx_video — PrunaVAED decoder

**Source:** https://github.com/ScryptHunter/ComfyUI-PrunaVAED (ComfyUI v0.30.0, Aug 3)  
**Action:** Place `prunavae_ltx23.safetensors` in `models/vae/`. ComfyUI-LTXVideo auto-detects. Also available as standalone ComfyUI-PrunaVAED node.  
**Impact:** 1.7–2.1× faster decode, −50% peak VRAM during decode phase. No change to diffusion inference or output quality. Directly benefits the 16 GB ceiling for long LTX-2.3 clips.  
**Risk:** Low — true drop-in (encoder and latent format unchanged).

### 3. build_sam3_segment / build_sam3_mask / build_sam3_extract — SAM 3.1 Multiplex

**Source:** https://ai.meta.com/blog/segment-anything-model-3/ (Meta, Mar 27; ComfyUI native Apr 27, PR #13408)  
**Action:** Download `sam3.1_multiplex` checkpoint; select in existing SAM3 node.  
**Impact:** Processes up to 16 objects in one forward pass. 7× throughput speedup at high object count, doubles FPS (16→32) on H100 (proportional gain on RTX 5060 Ti). ~4 GB VRAM.  
**Risk:** Low — backward-compatible checkpoint swap.

### 4. build_rembg_birefnet — Lucida model (transparent-object BiRefNet fine-tune)

**Source:** https://github.com/egeorcun/lucida / ComfyUI-RMBG v3.1.0 (Jul 21, bundled)  
**Action:** Update ComfyUI-RMBG to v3.1.0 via ComfyUI Manager; select `Lucida` in the BiRefNet node for glass/VFX/camouflage subjects.  
**Impact:** Solid-part transparency recall improves from 0.31 → 0.98 in transparent-object test suite. MIT license. Backward-compatible with existing BiRefNet workflows.  
**Risk:** Low — model-selector change, same node API.

### 5. build_rembg / build_rembg_v3 — BEN2 (Confidence Guided Matting)

**Source:** https://github.com/PramaLLC/BEN2 (bundled in ComfyUI-RMBG v3.1.0)  
**Action:** Same RMBG v3.1.0 update above; select `BEN2` for portraits with complex hair.  
**Impact:** Two-stage pipeline (coarse mask → low-confidence-pixel refinement). Stronger on fine hair, 4K images, semi-transparent edges. ~3 GB VRAM.  
**Risk:** Low — selector change, same node.

### 6. build_faceswap / build_faceswap_model / build_video_reactor — ReActor v0.6.2 + HyperSwap 256

**Source:** https://github.com/Gourieff/ComfyUI-ReActor/releases (Apr 25, 2026)  
**Action:** Update ReActor node; place `hyperswap_1c_256.onnx` in `models/hyperswap/`; select in node.  
**Impact:** Doubles swap face resolution 128 px → 256 px output. Same ONNX inference footprint (~2 GB VRAM).  
**Risk:** Low — drop-in model selector. Known minor bug on certain CPU float-normalisation configs (GitHub #208); test before production.

**Notes:** Could unify `build_txt2img` and `build_qwen_edit` into one backbone. Different sampler chain; workflow rework needed but well-documented. Moderate confidence (0.82).
