## Tier 1 — drop-in supersessions (ship soon)

*Weight/model swap only — no new node-pack installs required.*

### SAM 3.1 → `build_sam3_segment`, `build_sam3_mask`, `build_sam3_extract`
- **Source:** https://ai.meta.com/blog/segment-anything-model-3/
- **Released:** 2026-03-27
- Object Multiplex: shared-memory joint tracking of multiple objects simultaneously. Faster than SAM 3 at same accuracy. ComfyUI core PR #13408 already merged.
- **Action:** Download SAM 3.1 weights, update checkpoint name in builders.

### HyperSwap 256 ONNX → `build_faceswap`
- **Source:** https://github.com/Gourieff/ComfyUI-ReActor | models at https://hf.co/facefusion/models-3.3.0
- 2× resolution over inswapper_128 (256 vs 128 crop). Three variants: `hyperswap_1a_256.onnx` (speed), `hyperswap_1c_256.onnx` (quality). No InsightFace C++ build tools required.
- **Action:** Drop `.onnx` files in `ComfyUI/models/hyperswap/`. Update `swap_model` default in `build_faceswap`.

### HunyuanVideo 1.5 → `build_hunyuan_video`
- **Source:** https://hf.co/tencent/HunyuanVideo-1.5
- **Released:** 2025-11-24
- 8.3B params, Selective and Sliding Tile Attention (SSTA), built-in video SR, FP8 gemm.
- **Action:** Verify spellcaster is not already on 1.5; if not, weight swap.

### Qwen-Image-2.0 + DiffSynth ControlNets → `build_qwen_edit`
- **Source:** https://hf.co/Comfy-Org/Qwen-Image-Edit_ComfyUI
- Qwen3-VL encoder, 1K-token prompts, multilingual. DiffSynth ControlNets (canny/depth/inpaint) + Union LoRA (lineart/openpose) added March 2026. Native ComfyUI support.
- **Action:** Model file swap from Qwen-Image-2512; download ControlNet adapters.

### SeedVR2 v2.5 → `build_seedvr2_video_upscale`
- **Source:** https://github.com/numz/ComfyUI-SeedVR2_VideoUpscaler
- Incremental March 2026 update. Q6/Q8 GGUF quants fit 16 GB.
- **Action:** Check numz repo for latest checkpoint path, update model reference.

## Tier 2 — additive new builders (needs node-pack install)

### LTX Video 2.3 → upgrade `build_ltx_video`
- **Source:** https://github.com/Lightricks/ComfyUI-LTXVideo
- 22B params, native audio-video sync, portrait 9:16, 4K/50fps, spatial + temporal upscalers. Fits 16 GB with FP8 per official docs.
- **Action:** Update ComfyUI-LTXVideo node pack (≥ v0.16.1) + download new model weights.

### Ideogram 4 → new `build_ideogram4_txt2img`
- **Source:** https://hf.co/rectangleworm/ideogram-4-gguf (GGUF, **IN WINDOW** June 12) | https://hf.co/ideogram-ai/ideogram-4-fp8
- 9.3B NextDiT/Lumina2-family + Qwen3-VL-8B encoder. Structured JSON prompts (colour palette, bounding-box layout, text placement). #1 DesignArena open-weight at launch. GGUF Q4/Q8 fits 16 GB; NVFP4 for RTX 50-series. Active LoRA ecosystem this week.
- **Licence:** Non-commercial (Ideogram Non-Commercial Model Agreement) — note in builder docstring.
- **Action:** ComfyUI 0.24.0 native support already merged. Add ComfyUI-GGUF plugin for GGUF variant.

### Microsoft Lens → new `build_lens_txt2img`
- **Source:** https://hf.co/Comfy-Org/Lens | https://github.com/microsoft/Lens
- 3.8B dual-stream MMDiT with GPT-OSS-20B encoder + FLUX.2 VAE. 3 variants: Base (50-step), Standard (20-step), Turbo (4-step). FLUX.1-dev quality at 19% training compute. Fits 16 GB with CPU-offloaded encoder.
- **Action:** Download from Comfy-Org/Lens; use ComfyUI 0.23.0 Lens nodes.

### WAN 2.7 → upgrade `build_wan_video`, `build_wan22_t2v`, `build_wan_animate_video`, `build_wan_video_blockswap_t2v`
- **Source:** https://blog.comfy.org/p/wan27-is-now-available-in-comfyui
- Multimodal (text + image + audio + video). Up to 5 face refs, vocal timbre reference, 3×3 grid generation, 1080P. MoE architecture. **API-only via Partner Nodes** — no local weights published.
- **Action:** Install WAN 2.7 Partner Node; replace WAN 2.2 local workflow with API-based calls.

### Seedance 2.0 → additive for FLF-style workflows
- **Source:** https://blog.comfy.org/p/seedance-20-is-now-available-in-comfyui
- ByteDance. 2K cinema output, native audio-video sync, FLF, T2V, reference-to-video. Quality competitive with WAN 2.7 for FLF use case. **API-only.**
- **Action:** Install Seedance 2.0 Partner Node; add as alternative in `build_wan_flf`.

### TripoSplat → new `build_triposplat_3d`
- **Source:** https://blog.comfy.org/p/bringing-native-support-for-3d-gaussian
- Image → 3D Gaussian Splat (.ply / .splat / .spz / .ksplat). Native GAUSSIAN type in ComfyUI 0.23.0. Up to 262,144 Gaussians. Unreal/Unity/Blender (SuperSplat/SparkJS) compatible. Additive to Hunyuan3D builders (different output format).
- **Action:** ComfyUI 0.23.0 already supports it; add builder wrapping TripoSplat + GAUSSIAN export nodes.

### BFS-Best-Face-Swap LoRA → additive `build_bfs_faceswap`
- **Source:** https://hf.co/Alissonerdx/BFS-Best-Face-Swap
- Generative LoRA on Klein/FLUX.2 (BFS Face V1–V5 + BFS Head V1–V5). No 128px crop limit; better hair edge blending and lighting. 345K+ downloads. MIT licence. Klein 4B ≈ 8–12 GB VRAM.
- **Action:** New builder as high-quality alternative to inswapper paradigm; requires Klein base model.

### ComfyUI-PuLID-Flux2 → extend `build_faceid_img2img`
- **Source:** https://github.com/iFayens/ComfyUI-PuLID-Flux2
- v0.6.2, March 2026. PuLID face-ID injection for FLUX.2 Klein (4B/9B) + Dev. Klein 4B ≈ 8–10 GB; Klein 9B ≈ 14–15 GB (tight but within 16 GB).
- **Action:** Install node pack; add Klein-variant path to `build_faceid_img2img`.

### ToonOut BiRefNet ONNX → additive option in `build_rembg_birefnet`
- **Source:** https://hf.co/sprited/birefnet-toonout-onnx (**IN WINDOW** June 12)
- BiRefNet fine-tuned on anime/cartoon dataset. Better pixel accuracy on animated characters. ONNX → fast CPU/GPU inference, <4 GB VRAM. ComfyUI-RMBG already supports it.
- **Action:** Add `model="ToonOut"` option to `build_rembg_birefnet`.

### PixelDiT 1300M → additive T2I option
- **Source:** https://hf.co/nvidia/PixelDiT-1300M-1024px
- 1.3B pixel-space DiT (no VAE). Gemma 2B text encoder. Extremely VRAM-friendly. NSCLv1 non-commercial licence.
- **Action:** New additive builder; ComfyUI 0.23.0 PixelDiT + ResolutionSelector nodes.

### HiDream-O1-Image → new unified builder
- **Source:** https://hf.co/Comfy-Org/HiDream-O1-Image | https://github.com/Saganaki22/HiDream_O1-ComfyUI
- 6B Pixel-level Unified Transformer (UiT). T2I + instruction editing + subject-driven personalisation + storyboard in one model. MIT licence. FP8 quant ≈ 10 GB VRAM.
- **Action:** Install HiDream_O1-ComfyUI node pack; new builder wrapping UiT T2I + edit modes.
