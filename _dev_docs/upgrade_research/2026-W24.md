- **Repo:** `black-forest-labs/FLUX.2-small-decoder` (https://hf.co/black-forest-labs/FLUX.2-small-decoder)
- **Released:** April 6, 2026 — Apache 2.0
- **Impact:** All builders using FLUX.2 VAE (`build_klein_*`, `build_txt2img` flux arch, `build_pulid_flux`)
